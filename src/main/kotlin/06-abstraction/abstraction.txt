
+abstraction គឺជាគោលការណ៍មួយនៅក្នុង OOP ដែលវាមាននាទីនៅក្នុងការលាក់បាំងនូវទិន្នន័យឬលាក់នូវ
ព័ត៌មានលម្អិត(Implement Details) ហើយវាបង្ហាញតែលក្ខណះសំខាន់ៗដែលអ្នកប្រើប្រាស់គួរតែដឹងប៉ុណ្ណោះ។

+នៅក្នុង abstraction គេចែកវាចេញជា ២ ប្រភេទ៖
    ១. abstract class
    ២. interface

+យើងគួរតែប្រើប្រាស់ abstraction ក្រោមមូលហេតុដូចជា ៖
    ១. កាត់បន្ថយភាពស្មុគស្មាញ ដោយគ្រាន់តែដឹងពីមុខងារតួនាទីមិនចាបាច់ដឹងពីការលម្អិតទេ
    ២. សុវត្ថិភាពកូដ
    ៣. ងាយស្រូលនៅក្នុងការថែទាំកូដ កែប្រែផ្នែកខាងក្នុងនៃកូដដោយមិនឲ្យប៉ះពាល់ដល់កូដទៃ
    ៤. កូដមានស្តង់ដា ដោយកំណត់ Rule ច្បាស់សម្រាប់ class ដទៃធ្វើតាម

+ abstract class គឺជា classមួយដែលមិនអាចបង្កើត object បានដោយខ្លួនឯងទេ ប៉៉ុន្តែclassនោះអាចមាន
Properties, constructor, methods, abstract methods ។ ហើយដើម្បីឲ្យ class នោះទៅជា abstract
class និង method បានត្រូវប្រើប្រាស់ keyword (abstract)។

+ Interfaces គឺជាកិច្ចសញ្ញា ឬ ច្បាប់មួយនៃកូដដែលប្រាប់ទៅលើ class ថាមាន method ណាខ្លះ។ ហើយ
method ទាំងអស់នៅក្នុង Interface គឹសុទ្ធតែជា abstract method ដែលជា default ។
