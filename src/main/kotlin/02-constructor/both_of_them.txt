package `02-constructor`

+ Primary Constructor គឺជា constructor មួយបែបដែលត្រូវបានបង្កើតឡើងនិងសរសេរវានៅខាងក្រោយ
នៃឈ្មោះរបស់ class ។ ដោយវាប្រើប្រាស់សម្រាប់ធ្វើការ initialize Properties នៅពេលបង្កើត object។

+ Secondary Constructor គឺជាប្រភេទ constructor មួយបែបទៀតដែលប្រើប្រាស់នូវ Keyword constructor
នៅក្នុង bodyនៃ class។ ហើយវាភាគច្រើនគេប្រើប្រាស់វានៅពេលគេចង់ឲ្យ class មួយនោះមាន constructor បាន
ច្រើនទម្រង់ដែលយើងហៅថា overloading constructor។

+ Init {} គឺជា Initializer block ដែលវានឹងដំណើរការ automatically នៅពេលដែល object វា
ត្រូវបានបង្កើតឡើង ។លើសពីនេះជាទូទៅ គេប្រើប្រាស់វានៅពេលដែល ៖
    ១. initialize data
    ២. Validate data
    ៣. Run code when object created and access Primary constructor parameter

+ require() គឺជា Function ដែលប្រើសម្រាប់ Validate Input ឬ Check Condition។
 បើ Condition មិនត្រឹមត្រូវ វានឹង Throw Exception Error។
